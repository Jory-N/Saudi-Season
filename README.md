# Saudi-Season
We used display: inline-flex on .homepage. cards container to align the card elements horizontally in a flexible layout while keeping the container itself inline-level. 
https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Flexbox

We used float: left and float: right on the navigation arrows to shift the previous button to the left side and the next button to the right side of the container so that content flows around them.
https://developer.mozilla.org/en-US/docs/Web/CSS/float

https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Flexbox
